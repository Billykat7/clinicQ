{#- The map view (Issue 33): the clinics in the list, as pins. The map is an enhancement layered on a list that already works: discover-map.js draws a pin for each clinic card in #results and nothing else, so the map cannot disagree with the list. Leaflet (vendored) is loaded only when the map is first shown, so the list view pays nothing for it. Pins differ by shape as well as colour (a square for public, a diamond for private, as on the badges); nearby pins cluster; a pin opens a preview that is a copy of that clinic's own card, with Directions. If the map tiles do not arrive, the map gives way to the list with a sentence saying why, never a blank grey area. The OpenStreetMap attribution is the tile licence's requirement. -#}
