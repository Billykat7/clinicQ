{# Signed-in icon rail (Issue 53). Server-rendered main navigation for the app shell. Every link renders from the declarative nav registry (Issue #104): ``nav.visible(key)`` evaluates the caller's effective grants against ``src/core/nav_registry.py``, and grouped rail icons read ``nav.group_visible(key)`` / ``nav.group_href(key)``. A user only ever sees the destinations their role can reach: a link they cannot use is never rendered, and guessing its URL returns 403 (see routes.py). Change a grant in the RBAC admin and the rail follows with no template edit. Rendered only when ``show_side_bar`` is true (a valid signed-in shell). Icons are inline SVG with no inline styles or handlers, keeping the CSP unchanged. Each item carries a ``nav-*`` class that sets its accent hue (see admin.css) so the rail reads as a set of distinct destinations rather than a column of identical grey glyphs. #}
