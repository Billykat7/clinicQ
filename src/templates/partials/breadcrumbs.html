{# Reusable breadcrumb trail (Issue #118, M20). Renders the ``breadcrumbs`` context var (a list of ``{label, href?, current?}``) beneath the page title. The trail always starts at a home crumb linking to the dashboard, drawn here rather than repeated in every trail: a route (or ``web.context.default_breadcrumbs``) supplies only the part below home. An empty list is therefore still a trail (home, as the current page), while an *absent* ``breadcrumbs`` renders nothing at all, which is how the public pages opt out. The last item is the current page (``current: true``), rendered as static text with ``aria-current="page"``; earlier items link. Accessible (``nav[aria-label="Breadcrumb"]`` + ordered list) and truncates gracefully on small screens (see ``.breadcrumbs`` in admin.css). The trail draws as one connected pill of arrow-shaped segments: each crumb points into the next, the current page takes a brand-tinted fill and closes the pill. The shape is entirely CSS (``clip-path``) over this plain list, so the markup stays a semantic ordered list for assistive tech: the arrows are decoration, not content. #} {% macro home_icon() %} {% endmacro %} {% if breadcrumbs is defined %}
